# Merge Feature Branches and Resolve Conflicts

## Task Brief
Create intentional merge conflicts, resolve them manually, and document the resolution process in your capstone repo.

## Scenario
Your team needs to merge feature branches. Create conflicting branches, trigger a conflict, resolve it, and document the process.

## Deliverables
- Feature branches with intentional conflicts
- Resolved merge with clean history
- Conflict resolution documentation

## Success Criteria
- Merge conflict successfully resolved
- Clean commit history after merge
- Documentation explains resolution steps
