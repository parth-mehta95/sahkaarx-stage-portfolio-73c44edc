# Language and Stack Declaration in README

## Task Brief
Declare your chosen programming language (Python, JavaScript/TypeScript, Java, C#, or Go) and provide instructions for running code samples.

## Scenario
Your portfolio README must clearly state the programming language and how to run all code samples for reviewers.

## Deliverables
- Language declaration in README
- Instructions for running samples
- Example command or script

## Success Criteria
- Language clearly stated
- Run instructions are clear
- Code samples are executable
