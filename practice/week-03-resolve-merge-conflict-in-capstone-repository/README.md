# Resolve Merge Conflict in Capstone Repository

## Task Brief
Create conflicting branches, trigger a merge conflict, resolve it manually, and document the resolution process in your repo.

## Scenario
Your team merged conflicting changes to main. Resolve the conflict, test the fix, and document steps in README.

## Deliverables
- Resolved merge with conflict markers removed
- Conflict resolution documentation in README

## Success Criteria
- Merge completes without errors
- README explains conflict cause and resolution
