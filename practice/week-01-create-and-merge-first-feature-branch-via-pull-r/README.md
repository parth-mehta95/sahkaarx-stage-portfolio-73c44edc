# Create and Merge First Feature Branch via Pull Request

## Task Brief
Create a feature branch, make code changes, open a pull request with description, request review, and merge to main.

## Scenario
Your team uses feature branches and PRs for all changes. Create your first feature branch and complete the PR workflow.

## Deliverables
- Feature branch with meaningful name
- Pull request with detailed description
- Merged PR visible in main branch

## Success Criteria
- PR description explains changes clearly
- At least one commit in feature branch
- PR successfully merged to main
