# Submit and Merge First Pull Request

## Task Brief
Create a feature branch, commit code changes, open a PR with description, request review, and merge to main branch in your capstone repo.

## Scenario
Your team lead asks you to add a Python sample file and submit it via PR for code review before merging.

## Deliverables
- Feature branch with 2+ commits
- Merged pull request with review comments

## Success Criteria
- PR title and description are clear
- At least one approval received
