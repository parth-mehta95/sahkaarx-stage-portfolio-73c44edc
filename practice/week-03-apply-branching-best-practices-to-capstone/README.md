# Apply Branching Best Practices to Capstone

## Task Brief
Organize your portfolio with feature branches following professional naming conventions and clean merge workflow.

## Scenario
Your team standardizes branch naming. Reorganize capstone work using feature branches with clear, professional names.

## Deliverables
- Multiple feature branches with clear naming
- Branch organization in README
- Branches tracked on remote

## Success Criteria
- Branch names follow convention (feature/*, bugfix/*)
- All branches pushed to remote
- README documents branching strategy
