# Resolve Merge Conflicts and Add Exception Handling Code

## Task Brief
Create conflicting branches, resolve merge conflicts manually, and add exception handling code samples to your portfolio.

## Scenario
Your team needs to merge feature branches with conflicts. Create intentional conflicts, resolve them, and add error handling code.

## Deliverables
- Feature branch with exception handling code
- Resolved merge with clean history
- Third pull request merged to main

## Success Criteria
- Merge conflict resolved manually
- Exception handling code samples added
- PR merged with clean commit history
