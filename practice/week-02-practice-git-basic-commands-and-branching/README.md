# Practice Git Basic Commands and Branching

## Task Brief
Apply Git commands and branching workflows in your capstone repo through hands-on feature branch creation and management.

## Scenario
Reinforce Git fundamentals by creating and managing feature branches with clean commits in your portfolio repo.

## Deliverables
- Feature branch with meaningful name
- Multiple atomic commits with clean messages
- Branch pushed to remote

## Success Criteria
- Feature branch created and tracked remotely
- Commits follow atomic and message best practices
- Branch ready for pull request
