# Language and Stack Declaration

## Task Brief
Declare your chosen programming language (Python, JavaScript/TypeScript, Java, C#, or Go) in your portfolio README.

## Scenario
Your portfolio README must clearly state the programming language and how to run the code samples.

## Deliverables
- README with language declaration
- Instructions for running code samples
- Language-specific file examples

## Success Criteria
- Language clearly stated in README
- Setup instructions are clear
- Code examples use chosen language
